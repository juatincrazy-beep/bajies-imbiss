# Bilder für den Imbiss

Lege PNG-Dateien mit **genau diesen Namen** hier ab, dann ersetzen sie die Platzhalter (Emojis) von selbst:

| Datei | Bedeutung |
|---|---|
| `background.png` | Hintergrund (16:9, z. B. 1920 × 1080) |
| `bajie.png` | Bajie am Stand (freigestellt, transparenter Hintergrund) |
| `guests/<id>.png` | Gast: `villager`, `hungry_ghost`, `fox_spirit`, `crane`, `ogre`, `turtle` (freigestellt) |
| `dishes/<id>.png` | Gericht (noch nicht benutzt): `rice_bowl`, `peach_bun`, `tofu_soup`, `mushroom_dumplings`, `bamboo_stirfry`, `cold_peach_dessert`, `honey_cake`, `spicy_pot` |

Nach dem Hineinkopieren in Godot kurz warten (Import), dann F5.
